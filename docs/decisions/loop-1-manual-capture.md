# 决策卡：闭环 1｜手动收录岗位

> 版本：v1.0  
> 状态：已确认，可实现  
> 关联：PRD V1、D-006、D-007、H-001 至 H-003

## 用户目标

当用户在官网、牛客、BOSS 或公众号看到岗位时，能在 30 秒内把它收录为可后续评估的记录，不丢失来源、DDL 或关键备注。

## 字段

| 字段 | 规则 |
|---|---|
| 公司 `company` | 必填 |
| 岗位 `title` | 必填 |
| 工作地点 `city` | 必填；自由文本，接受“全国”“多地”“远程” |
| 投递链接 `application_url` | 选填 |
| 薪资 `salary_range` | 选填 |
| 部门/业务线 `department` | 选填；用于候选重复判断 |
| 截止日期 `deadline` | 选填；临近或逾期仍可保存 |
| 来源 `source` | 选填：官网、BOSS直聘、牛客、公众号、其他 |
| 备注 `note` | 选填 |
| 状态 `status` | 系统字段，默认“待评估” |

## 状态与主操作

- 本闭环只有一个业务状态：`待评估`。
- 主操作：**保存并收录**。
- 不出现匹配分数、收藏、待投递、已投递、检查单、邮件或申请阶段。

## 反馈与异常

| 场景 | 反馈与行为 |
|---|---|
| 正常保存 | 绿色提示“已收录：公司 · 岗位”；清空表单；提供“查看岗位池”入口 |
| 缺少必填字段 | 在对应字段附近显示明确错误；不写入数据 |
| DDL 在未来 3 天内 | 标记“临近截止”，允许保存 |
| DDL 已过期 | 标记“已逾期”，允许保存 |
| 同公司 + 岗位 + 城市候选重复 | 不静默创建；展示原记录，提供查看、更新原记录、确认不是重复并继续收录 |
| 应用重启 | 已保存记录保持可见 |

## 非目标

- 不解析原帖、图片或表格；
- 不做画像、匹配、筛选、投递或邮件同步；
- 不阻止用户保存临期、逾期或确认非重复的岗位。

## 验收标准

- 连续保存 5 条岗位，成功后表单均自动清空；
- 保存、必填校验、候选重复、临近截止与逾期均有自动化测试；
- SQLite 持久化在重启后保留；
- 桌面优先、移动端支持查看和快速录入；视觉为克制的蓝色系。
