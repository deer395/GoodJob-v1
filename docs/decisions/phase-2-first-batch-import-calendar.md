# 决策卡：Phase 2 第一批｜本地表格导入与 ICS 导出

状态：已确认并已实现。版本：修订版 v3（2026-08-06）。

## 用户目标

将已有 CSV/XLSX 岗位表安全、可追溯地收录进岗位池，并把用户主动安排的关键日期导出到本地日历；不改变最终投递权或既有申请记录。

## 范围与数据

- 导入支持 `.csv`、`.xlsx`；本地解析，最多 5MB、1000 行、30 列；`.xls` 明确拒绝。
- 提供表头映射、默认秋招年份补全日期、前 10 行预览、库内/文件内重复提示和逐行跳过/覆盖/新建选择。
- `ImportBatch` 记录文件、时间、结果、映射和默认年份；岗位以 `source_import_id` 追溯来源。
- `ApplicationEvent.scheduled_at` 仅记录用户填写的实际安排时间；`event_date` 仍是通知/发生日期。
- ICS 仅导出未投递 DDL、具备 `scheduled_at` 的测评/笔试或面试、以及下一步计划时间。

## 保护与非目标

- 覆盖只更新公司、岗位、城市、链接、薪资、DDL、来源的非空值；绝不覆盖收藏、状态、部门、备注、匹配信息或重复确认标记，也不触及申请、事件、清单和画像。
- 不实现 `.xls`、云端上传、外部日历同步、提醒、邮件解析、OCR、AI、爬虫或自动投递。
- ICS 为用户下载后自行导入的本地文件，不会写回或同步外部日历。

## 验收

- 自动化覆盖 XLSX 自动映射、无年份日期提示、覆盖保护、事务回滚、批次追溯、来源关联与匹配重算。
- 自动化覆盖 ICS 的资格过滤、稳定 UID、CRLF 与空 `scheduled_at` 排除。

## v2 变更记录

用户用真实校招表验证时，文件包含 659 条岗位，且工作表的已用区域元数据错误标为 `A1`。为保证真实来源可直接使用，行数上限由 500 提升至 1000；读取 XLSX 时重置不可信的区域元数据，并将缺少公司、岗位或城市的行默认跳过、汇总提示。该调整不扩大文件大小、列数、外部数据或自动写入边界。

## v3 变更记录

紧急回归确认 ICS 不应把通知或已发生事实写入日历。仅导出具备 `scheduled_at` 的实际测评/面试安排；排除测评通知、笔试通知、已投递事件和已结束申请的全部事件/下一步计划。岗位 DDL 继续仅限无 Application 或待投递 Application。
