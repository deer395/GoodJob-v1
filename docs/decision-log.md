# CampusAI 决策日志

> 记录“为什么这样做”，不重复记录实现细节。  
> 更新规则：每个决策确认时立即新增；阶段结束时复盘其结果。

## 维护规则

| 文档 | 何时更新 | 更新方式 |
|---|---|---|
| 本决策日志 | 每一项产品、范围、架构或数据边界决策确认时 | 追加一条，不改写历史结论 |
| PRD | 闭环验收完成，或目标、范围、技术路线发生实质变化时 | 更新“当前事实”，在本日志链接对应决策 |
| 机会—方案树 | 新研究改变机会优先级、方案或实验结论时 | 更新评分、假设和实验结果 |
| 决策卡 | 开始实现前确认；实现中发现需要改变时 | 增加版本与变更记录，重新确认受影响验收 |
